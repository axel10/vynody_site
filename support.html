01 / CONTACT

联系技术支持

请发送邮件至 zgmf300@outlook.com。这是 Vynody 的官方技术支持邮箱，可用于咨询使用问题、反馈功能建议和报告应用异常。

为了更快帮到你

请尽量说明设备型号、系统版本、Vynody 版本、问题发生的时间和复现步骤；如方便，也可附上截图或录屏。请勿发送 API Key、访问令牌或其他敏感信息。

02 / HELP

常见帮助

A

找不到本地音乐

请确认已在系统设置中允许 Vynody 访问音乐或文件，并在应用内重新扫描包含音乐文件的文件夹。

B

歌词或标签无法获取

在线歌词、歌曲识别和标签补全需要网络连接。请检查网络状态，并确认歌曲标题、艺术家等信息尽量准确。

C

局域网共享无法连接

请确认两台设备处于同一可信局域网，并已授予 Vynody 局域网访问权限；部分网络或防火墙可能会阻止设备互相发现。
